# Data sources

| Source id | What | Fetched from | Trusted for | Known defects (all observed in this build) | License |
|---|---|---|---|---|---|
| `wikipedia_constituents` | Current S&P 500 list (Symbol, Security, GICS sector/sub-industry, HQ, Date added, CIK, Founded) | `https://en.wikipedia.org/wiki/List_of_S%26P_500_companies` | Today's members, tickers, sector, CIK; *claims* about entry dates | "Date added" frequently keeps a predecessor's date after a merger/rename (Linde shows Praxair's 1992; PSKY shows 1994) and changes between revisions (3M: 1976-08-09 in 2021, 1957-03-04 in 2024) | CC BY-SA 4.0 |
| `wikipedia_changes` | "Selected changes" table (~405 rows) with reasons and citations | `https://en.wikipedia.org/wiki/Historical_components_of_the_S%26P_500` | Dated, cited exit/entry events with reasons; the ticker on REMOVE rows | Sparse before 2008 (2000: 7 rows, 2003: 1, 2005: 2); ADD rows often carry the company's *later* name/ticker (ACT/Actavis 1999, CB/Chubb 2010); some rows wrong (MPC 2011 named "Marathon Oil"; 2016 lists ACE as removed); markup artefacts ("ALLE \|"); two rows lack the Refs cell | CC BY-SA 4.0 |
| `wikipedia_revision` | The constituents page as it stood on 2007-07-01 and 1 Jan 2008…2026 (via `oldid`) | MediaWiki API revision lookup + `index.php?oldid=` | Independent point-in-time witness for membership, tickers, names and GICS sector on those dates | Layouts vary (parser matches headers by meaning); 2008 column is "Industry"; 2025 header typo "Securit"; 2006 and Jan-2007 revisions have no table | CC BY-SA 4.0 |
| `reference_fja05680` | Daily ticker sets 1996-01-02 → present (Clenow/Norgate 1996–2019, then maintained from Wikipedia + research by the author) | `https://raw.githubusercontent.com/fja05680/sp500/master/…` | Dense coverage of the 2001–2010 gap; corroboration of dates; membership counts | Tickers are back-filled to the lineage's *last* symbol (AABA for Yahoo since 1999, USB over Firstar, T over SBC), so two legal entities can collapse into one interval; bankrupt issuers carry a trailing "Q" (WAMUQ, CITGQ); the author notes the first ~5 years may miss symbols (487 in 1996 vs 494+ from 2001) | MIT (copyright Farrell J. Aultman) |
| `curated` | `data/curated/*.csv` | this repository | Hand-verified identity links and event corrections | Every row cites a URL; see `data/curated/README.md` | MIT |

Fetch policy: user agent `snp500-research/0.1 (…)`, 1 request/second, cached snapshots reused for one day (current pages) / thirty days (reference) / forever (immutable revisions). All bodies are retained under `data/raw/` (≈25 MB per full scrape).

Not used (and why): S&P Dow Jones Indices announcement PDFs are cited by Wikipedia rows and are stored as `refs` on events, but are not scraped because they are not machine-readable across 25 years; SEC EDGAR is used only for the CIK column carried by Wikipedia (full 8-K parsing is a documented future extension in `OPERATIONS.md`).
